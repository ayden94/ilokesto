# Utilinent

`@ilokesto/utilinent`는 JSX가 지저분해지기 쉬운 rendering pattern을 작은 React utility component로 정리하는 패키지입니다. 조건부 렌더링, list rendering, 반복 node, switch-style branch, intersection 기반 lazy rendering, async mount, slot, polymorphic proxy tag를 다룹니다.

React state, routing, data fetching, component library를 대체하지 않습니다. UI intent가 markup 안에서 잘 보이도록 작은 선언적 building block을 제공합니다.

## 설치

```package-install
@ilokesto/utilinent
```

`react`는 peer dependency이므로 app에 이미 설치되어 있어야 합니다.

## 최소 예시

```tsx lineNumbers
import { For, Show } from '@ilokesto/utilinent';

type User = { id: string; name: string };

export function UserList({ users, loading }: { users?: User[]; loading: boolean }) {
  return (
    <Show when={!loading} fallback={<p>Loading users...</p>}>
      <For.ul each={users} fallback={<p>No users found.</p>}>
        {(user) => <li key={user.id}>{user.name}</li>}
      </For.ul>
    </Show>
  );
}
```

`Show`는 조건 branch를 처리합니다. `For.ul`은 실제 `<ul>` 안에 list를 렌더링하고, 배열이 비었거나 없으면 fallback을 보여줍니다.

## 제공하는 것

- [`Show`](/ko/utilinent/reference/show)로 조건부 렌더링.
- [`For`](/ko/utilinent/reference/for)로 list rendering.
- [`Repeat`](/ko/utilinent/reference/repeat)로 숫자 기반 반복.
- [`Switch`와 `Match`](/ko/utilinent/reference/switch-match)로 first-match branching.
- [`Mount`](/ko/utilinent/reference/mount)로 async child resolution.
- [`Observer`](/ko/utilinent/reference/observer)와 [`Slacker`](/ko/utilinent/reference/slacker)로 intersection 기반 rendering.
- [`Slot`과 `Slottable`](/ko/utilinent/reference/slot)로 slot-style prop merging.
- [`OptionalWrapper`](/ko/utilinent/reference/optional-wrapper)로 조건부 wrapping.
- [`PluginManager`](/ko/utilinent/reference/plugin-manager)로 custom proxy component 등록.
