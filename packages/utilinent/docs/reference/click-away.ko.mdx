# ClickAway

`ClickAway`는 element 바깥에서 pointer 또는 touch 이벤트가 발생할 때 `onClickAway`를 호출합니다. `ref`는 underlying `div`로 전달됩니다. popover, dropdown, menu를 닫을 때 적합합니다.

```tsx lineNumbers
import { ClickAway } from '@ilokesto/utilinent';

<ClickAway onClickAway={() => setOpen(false)}>{children}</ClickAway>
```

## Props

| Prop | Type | 설명 |
| --- | --- | --- |
| `onClickAway` | `(event) => void` | 바깥 pointer/touch 이벤트에서 호출됩니다. |
| `ignore` | `RefObject[]` | "안쪽"으로 간주할 추가 ref들입니다. |
| `pointerEvents` | `boolean` | `mousedown`/`touchstart` 대신 `pointerdown`을 감지합니다. |

표준 `div` props와 `ref`가 전달됩니다.
