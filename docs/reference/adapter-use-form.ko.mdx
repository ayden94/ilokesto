# 어댑터 useForm

모든 어댑터는 이미 만들어진 코어 폼에서 시작합니다. React, Vue, Solid는 `form`, `useRegister`, `useField`, `useFormState`를 반환합니다. 프레임워크마다 이벤트 이름은 다르지만 필드 옵션은 `RegisterOptions`를 공유합니다. 여기에는 `name`, 선택적인 `schema`, `schemaOptions`, `type`, `value`, `checkedValue`, `uncheckedValue`가 있습니다.

```ts lineNumbers
const react = useReactForm(form);
const vue = useVueForm(form);
const solid = useSolidForm(form);
const svelte = useSvelteForm(form);
```

Svelte는 의도적으로 다릅니다. `form`, `register` 액션, 읽기 가능한 저장소를 반환하는 `useFormState()`를 제공합니다. 같은 모양의 `useField`와 `useRegister`를 노출하지 않으므로 Svelte 예시는 액션 중심으로 작성해야 합니다. text input, checkbox, radio, select, multiple select 동작은 사용하는 프레임워크 통합 문서에서 확인하세요.

## 실무 사용 팁

추상화를 만들 때는 이 레퍼런스를 가까이 두세요. 레퍼런스는 패키지가 무엇을 노출하는지 설명하고, 가이드는 그 조각들을 조합하는 한 가지 방식을 보여줍니다. 어떤 도우미가 `FieldPathInput`, 검증 시점, 배열 재배치를 감춘다면 그 도우미도 같은 정밀도로 문서화하세요. 그래야 나중에 문자열, 튜플, 안정적인 키 중 무엇을 기대하는지 유지보수자가 알 수 있습니다.
