# Proxy registry internals

Proxy component는 base renderer, 알려진 HTML tag 전체, `Proxy` lookup을 조합해 만들어집니다. Property가 generated target에 있으면 바로 반환합니다. 없으면 요청된 category와 `base`를 `PluginManager`에서 확인합니다.

따라서 `Show.div`는 즉시 사용할 수 있고, `Show.Link`는 `PluginManager.register({ show: { Link } })` 이후 사용할 수 있습니다.

## Caching

Plugin-backed property가 resolve되면 utilinent는 specialized component를 현재 proxy target에 저장합니다. Property를 읽는 rendering code보다 먼저 plugin을 등록하세요.
