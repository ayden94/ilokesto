# 문제 해결

## `For`가 row 대신 fallback을 렌더링합니다

`each`가 `null`, `undefined`, empty array인지 확인하세요. List emptiness에는 `For`를 사용합니다. `Show`의 array truthiness는 length check가 아닙니다.

## `Show` branch가 `0`에서 렌더링되지 않습니다

`0`은 falsy입니다. Boolean condition을 따로 넘기고 numeric value는 별도로 렌더링하세요.

```tsx lineNumbers
<Show when={count !== null}>{count}</Show>
```

## `Show.Link`가 undefined입니다

먼저 `PluginManager.register`로 component를 등록하고, TypeScript를 위해 `UtilinentRegister` module augmentation을 추가하세요.

## Lazy loading이 시작되지 않습니다

Observed element에 size가 있는지 확인하세요. `Observer`는 최소 size default를 적용하지만 CSS가 element를 intersect 불가능하게 만들 수 있습니다.

## Next.js에서 hook 또는 browser API 오류가 납니다

`Mount`, `Observer`, `Slacker`, `useIntersectionObserver` 사용을 `'use client'`가 있는 Client Component로 옮기세요.
